# ecommerce-personalization-ml
ML-based E-Commerce Personalization Platform using UCI Online Retail dataset (~541k transactions). Features: K-means clustering, Isolation Forest (anomalies), Random Forest/NNs for churn/sales, Surprise recommenders, Thompson Sampling RL for optimization. Streamlit app; 15% simulated uplift. CS/ML portfolio project (Amazon). Sep 20-Oct 4, 2025.
